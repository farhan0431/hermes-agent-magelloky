about=Socket server plugin that exposes QGIS operations to LLMs through the
    Model Context Protocol. Enables AI agents (Magelloku, Claude, Cursor, etc.) to directly
    control QGIS: manage layers, edit features, run processing algorithms, render maps, and more.

    Attribution & Credit:
    - Original author and creator: Nicolas Karasiak (https://github.com/nkarasiak/qgis-mcp)
    - Forked and adapted for Maggeloku / Magelloku ecosystem by Farhan.

    Features:
    - 121 MCP commands for layers, features, processing, rendering, layouts, and PyQGIS validation
    - Diagnose tool for full stack health checks
    - Plugin development tools: message log, plugin reload, layer tree
    - Expression validation, project variables, settings access
    - Non-blocking TCP socket server with length-prefixed framing
    - Toolbar button with port configuration dropdown
